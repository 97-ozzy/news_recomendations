# Новостная рекомендательная система

Проект посвящён разработке рекомендательной системы для новостного контента на датасете **MIND-small**.  
Цель модели — по истории взаимодействий пользователя и содержанию новостей оценивать вероятность клика, ранжировать показанные материалы и рекомендовать наиболее релевантные.

Соревновательная цель проекта — результат, достаточный для попадания в **топ-10 Leaderboard**.

## Данные

Использовались два основных файла:

- `news.tsv` — 51 282 новости с категорией, подкатегорией, заголовком, аннотацией и дополнительными признаками;
- `behaviors.tsv` — 156 965 записей с историей пользователей, показанными новостями и кликами.

После удаления записей без истории взаимодействий осталось **153 727 строк**.

Для текстового представления новости заголовок и аннотация объединялись через специальный разделитель. Пропущенные аннотации заменялись пустыми строками.

Основные характеристики данных:

- медианная длина заголовка — 10 слов;
- медианная длина аннотации — 24 слова;
- медианное число новостей в одном показе — 24.

## Подход

### Baseline

Для каждой новости рассчитывался эмбеддинг размерности 384 с помощью модели `all-MiniLM-L6-v2`.

Представление пользователя формировалось как среднее эмбеддингов новостей из его истории, а релевантность кандидата оценивалась по косинусному сходству.

### Итоговая модель

История пользователя ограничивалась последними 50 новостями. Для каждой обучающей записи использовались:

- 1 положительный пример;
- 4 негативных примера.

Текстовые эмбеддинги новостей рассчитывались заранее, а текстовый энкодер был заморожен.

Архитектура модели включала:

- позиционные эмбеддинги;
- 3 Transformer-блока с multi-head attention;
- attention pooling для построения эмбеддинга пользователя;
- MLP-скорер.

Для пары «пользователь — новость» в скорер передавались:

1. эмбеддинг пользователя;
2. эмбеддинг новости;
3. их поэлементное произведение;
4. абсолютная разность эмбеддингов.

Модель обучалась 5 эпох с функцией потерь Cross Entropy и оптимизатором AdamW.

## Метрика

Основная метрика — **Group AUC**.

Она показывает, насколько часто модель присваивает кликнутой новости более высокую оценку, чем некликнутым кандидатам. AUC рассчитывался отдельно для каждого показа и затем усреднялся.

## Результаты

| Модель | Group AUC |
|---|---:|
| Baseline | ~0,628 |
| Итоговая модель | **0,6853** |

Дополнительные результаты итоговой модели:

- train loss: от 1,4660 до 1,4184;
- test loss: **1,4255**;
- прирост AUC: около **0,057**;
- относительный прирост: около **9%**.

> Сравнение с baseline является ориентировочным: baseline оценивался на первых 15 тысячах записей, а итоговая модель — на отдельной тестовой выборке с negative sampling.

## Выводы

В проекте реализован полный пайплайн рекомендательной системы: анализ и очистка данных, построение baseline, обучение нейросетевой модели и оценка качества.

Transformer-блоки и attention pooling позволили лучше учитывать порядок и важность новостей в истории пользователя, а расширенные признаки взаимодействия между пользователем и кандидатом улучшили качество ранжирования по сравнению с обычным косинусным сходством.

Возможные направления развития:

- оценка по MRR и nDCG;
- подбор гиперпараметров;
- добавление категориальных и временных признаков;
- фиксация официального результата Leaderboard.
